# Longform Agents

面向网文、漫画、漫剧、音乐等多模态长内容的多 Agent 协作框架。

## 背景

长内容生产对一致性要求极高。一部连载网文的角色设定、伏笔与世界观，一套漫画的分镜与角色，一部漫剧的剧情、画面与配乐，需要在几十上百个阶段之间保持连贯。

单次模型调用做不到这一点：没有跨阶段的上下文锚定与约束传递，内容会逐渐漂移、前后矛盾。这不是提示词能解决的，是结构问题。

Longform Agents 的解法是**多 Agent 协作**：Planner 把目标拆解为协作计划，多个分工的 Agent 按阶段执行；跨阶段约束通过协商台账传递，一致性由领域规则与骨架锚定。目标只有一个——长内容从第一步到最后一步，设定、逻辑、风格保持连贯。

## 核心能力

### Planner：目标到协作计划

把一句自然语言目标编译成带依赖关系的阶段计划：

- 意图识别、领域先验、自适应分解
- 计划生成后自动校验（步骤遗漏、依赖错误、该并行未并行），发现问题自动修订
- 支持自然语言人工修订，按意图重排而非推翻重来
- 按历史表现匹配阶段 Agent

计划使用统一契约 PlanSpec（`phase_id` 为唯一引用键），从规划到执行到落库结构一致、字段无损。

### 多 Agent 协作

- Agent 执行中可向同伴提问（`ask_peer`），以其结果继续，不是各自为政
- 跨阶段约束提取后写入协商台账，注入下游阶段并校验覆盖率，保证不丢失
- 运行中支持人工插话

### 工作流图执行引擎

阶段为图节点、依赖为边，互不依赖的阶段并行执行。支持串行、并行、DAG 三种形态。内建断点恢复（checkpoint）、运行锁、规则校验。每个 Agent 通过「模型 / 工具 / 技能」三维度配置。

### 领域知识与规则

领域定义、质量规则、阶段骨架以数据形式管理（`quality_domains` / `quality_rules`）。新增领域只需提供数据，不改代码。规则按领域定制——漫画审构图，音乐审节奏——这是长内容一致性的关键所在，也是最需要沉淀的部分。

### 长内容骨架

骨架系统保存作品已确立的设定（人物、世界观、伏笔）与逐章要点，Agent 执行时自动携带这些上下文。写后续章节时，前面的设定不会丢。

## 开源边界

**本仓库包含**：引擎全部核心——多 Agent 协作、Planner、工作流图执行、长内容骨架、领域知识与规则体系，以及网文、通用两个领域的知识数据（领域定义、质量规则、模板、知识包）。可 clone 运行、接入自有应用、扩展新领域。

**本仓库不包含**：成品化的平台产品——Web 控制台、产品体验打磨，以及漫画、漫剧、音乐等其余领域的完整知识数据。这些属于商业化产品。

## 当前状态

Alpha 阶段，API 与数据模型仍在演进。

| 能力 | 状态 | 说明 |
|------|------|------|
| 多 Agent 协作 | ✅ | `ask_peer` 真实调用同伴 + 协商台账 |
| Planner 规划 | ✅ | 自然语言 → 多阶段协作计划（PlanSpec） |
| 计划自动校验 / 人工修订 | ✅ | `plan_critic/refiner` + `plan_revision` |
| 工作流图执行 | ✅ | 串行 / 并行 / DAG，断点恢复 |
| 领域知识与规则 | ✅ | 数据驱动，扩展领域不改代码 |
| 长内容骨架 | ✅ | 设定与逐章要点锚定，防止前后矛盾 |
| 网文流程 | ✅ | 仅需 LLM |
| 漫画 / 漫剧 / 音乐流程 | ⚠️ | 需配置对应多模态模型 |
| 圆桌协作 / 自适应路由 | 🧪 | 实验性 |

## 快速开始

```bash
python3.11 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env        # 填入 DEEPSEEK_API_KEY

# 跑一个 demo：自然语言 → 领域识别 → 计划分解 → Agent 匹配
.venv/bin/python examples/run_demo.py

# 跑引擎测试
.venv/bin/python -m pytest tests/ -x -q
```

整体结构见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。接入自有应用，从 `core/orchestration/planner.py`（规划入口）和 `core/graph/runtime.py`（工作流图执行）入手。

## 安全说明

默认不启用认证，仅适用于本机或受信环境。生产部署前必须启用认证（`AUTH_ENABLED=true`）、配置独立密钥、限制 CORS、隔离工具执行环境。Shell 沙箱是尽力而为的防护，不是安全边界。
